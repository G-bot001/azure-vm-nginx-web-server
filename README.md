
# Nginx Web Server on Azure Virtual Machine

This project documents my hands-on experience setting up and configuring the Nginx web server on a Linux virtual machine hosted on Microsoft Azure.

## Objective

To gain practical experience with Azure Virtual Machines, Linux server administration, and web server deployment.

## Technologies

- Microsoft Azure Virtual Machines
- Linux
- Nginx
- Web browser for verification

## Work Completed

- Set up an Azure Virtual Machine running Linux.
- Installed and configured Nginx.
- Successfully accessed the hosted webpage through a web browser.

## Outcome

Successfully deployed and accessed a webpage served by Nginx on an Azure Virtual Machine.
